# Вопросы админам — флеш-карточки

Приложение в формате **PWA** с карточками для подготовки по вопросам из [devops-interview](https://github.com/Swfuse/devops-interview). На лицевой стороне — вопрос, по тапу карточка «переворачивается» и показывает ответ. Работает офлайн, устанавливается на телефон как приложение.

## Возможности

- **264 карточки** (вопрос + ответ), собранные из `questions.md`.
- Карточки показываются **в случайном порядке**.
- **Свайп влево/вправо** — следующая / предыдущая карточка; **тап** — переворот и показ ответа.
- **Полный ответ** со скроллом (код и списки сохраняются).
- **Диаграммы (SVG)** в ответах по актуальным темам (TCP-рукопожатие, DNS, NAT, RAID, Kubernetes, загрузка Linux и др.).
- **Полезные ссылки** в каждом ответе: документация по теме (man-страницы, официальные docs) и **разбор на YouTube** (быстрый поиск по вопросу).
- **Выбор темы** — фильтр по 15 категориям (Linux, Kubernetes, Сети, Docker, Железо, Базы данных и т.д.).
- Категория показана на карточке, есть **счётчик и прогресс-бар**.
- **PWA**: устанавливается на главный экран, работает **офлайн** (service worker).

## Структура

```
cards/
├── index.html          # страница-приложение
├── styles.css          # стили (мобильный-first)
├── app.js              # логика карточек, свайп, фильтр по темам
├── manifest.json       # PWA-манифест
├── sw.js               # service worker (офлайн-кэш)
├── data/
│   └── cards.json      # карточки [ {question, category, answer, image?, links?} ]
├── icons/              # иконки приложения (192, 512)
└── img/                # SVG-диаграммы для ответов
```

## Запуск локально

Нужен любой статический сервер (PWA требует HTTP/HTTPS):

```bash
cd cards
python3 -m http.server 8000
```

Откройте <http://localhost:8000> в браузере.

## Деплой на GitHub Pages

1. Запушьте ветку `main` в репозиторий:
   ```bash
   git add . && git commit -m "PWA карточки" && git push origin main
   ```
2. В настройках репозитория включите Pages: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
3. Приложение будет доступно по адресу `https://<username>.github.io/cards/`.

## Установка на телефон

1. Откройте адрес приложения в Chrome (Android) или Safari (iOS).
2. Android: меню браузера → **«Установить приложение»** / **«Добавить на главный экран»**.
   iOS: кнопка **Поделиться** → **«На главный экран»**.
3. Приложение работает офлайн (контент закэширован service worker'ом).

## Регенерация карточек из source

Карточки парсятся из `questions.md` (исходный markdown). Скрипты:

```bash
# распаковать карточки из questions.md -> cards/data/cards.json
python3 parse.py

# дописать ответы для неполных карточек
python3 enrich.py
python3 improve.py

# нормализовать категории и улучшить ответы
python3 finalize.py

# добавить полезные ссылки (документация + YouTube-поиск)
python3 links.py

# перегенерировать SVG-диаграммы
python3 gen_diagrams.py
```

Скрипты лежат в `../` (родительской папке репозитория), в сам репозиторий не попадают.

## Примечания

- Иконки и диаграммы генерируются автоматически (`gen_icons.py`, `gen_diagrams.py`).
- Список тем и содержимое карточек легко править в `data/cards.json`.
